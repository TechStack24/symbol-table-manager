What is a symbol table?

A symbol table is the compiler's database of every name in the program. For each identifier it stores attributes such as the kind (variable, function, parameter), data type, scope, line of declaration, storage size and offset. Almost every phase reads or updates it.

  • Lexical analysis creates identifier tokens; the first sighting may create an entry.
  • Syntax and semantic analysis insert declarations and look names up to check types, scope and arity.
  • Intermediate code and code generation read sizes, offsets and types to allocate memory.
  • Error reporting uses it for undeclared names, redeclarations and unused variables.

Operations

insert(symbol)Add a declaration to the current scope; reject duplicates in the same scope.
lookup(name)Search the current scope first, then each enclosing scope up to global.
delete(name)Remove a name from the current scope.
enter_scope()Push a new, empty table when a block, function or loop begins.
exit_scope()Pop the table when the block ends; its names are no longer visible.

Data structure used here

Each scope owns a hash table with separate chaining. The index is djb2(name) mod capacity, where h = h * 33 + char starting from 5381. When the load factor passes 0.75 the table doubles and every entry is rehashed. Insert and lookup take O(1) on average. Scopes form a stack, so lookup is O(depth × chain length) and inner names naturally shadow outer ones.

Compared with alternatives: a linear list is simple but O(n) per lookup, a sorted array or binary search tree gives O(log n), and a hash table is the usual production choice.

Checks performed with the table

  • Use of an undeclared variable or function
  • Redeclaration in the same scope; shadowing of an outer name (reported as info)
  • Wrong number or type of function arguments; conflicting prototypes
  • Type mismatches such as float to int narrowing; void values used in expressions
  • Return type mismatches and missing return
  • Variables used before initialization, or declared but never used
  • Constant array indexes outside the declared size; division by constant zero
  • break / continue outside a loop
